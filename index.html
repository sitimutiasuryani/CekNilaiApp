Panduan Hosting Gratis (Vercel / GitHub Pages)

Karena sistem ini dibuat dalam 1 file HTML, Anda bisa mempublikasikannya secara online secara gratis agar siswa dapat membukanya kapan saja dari HP/Laptop masing-masing.

Cara 1: GitHub Pages (Gratis & Mudah)

  1. Buat repositori baru di GitHub (misal: sicek-nilai).
  2. Upload file HTML ini dan beri nama file index.html.
  3. Masuk ke menu Settings > Pages.
  4. Pada bagian Branch, pilih main lalu klik Save.
  5. Website Anda langsung aktif dan bisa dibagikan ke siswa!

Cara 2: Vercel (Klik & Drop)

  1. Buka website Vercel.com dan login/daftar.
  2. Pilih Add New Project > Deploy via CLI/Git atau Drag & Drop folder berisi file index.html ini.
  3. Selesai! Vercel akan memberikan link domain khusus yang dapat diakses siswa.
Tips Keamanan: Siswa yang membuka link tidak bisa mengakses data siswa lain karena tombol "Portal Guru" dikunci dengan PIN.
